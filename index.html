02 · C tilida

C da scanf() va printf()

C tilida bu funksiyalar standart kiritish-chiqarish kutubxonasiga tegishli.

Kutubxona: <stdio.h>scanf() — kiritishprintf() — chiqarish
C kodi
#include <stdio.h>

int main(void) {
    int a;
    printf("Son kiriting: ");
    scanf("%d", &a);
    printf("Siz kiritgan son: %d\\n", a);
    return 0;
}

scanf("%d", &a);

Klaviaturadan butun sonni oladi. &a — o‘zgaruvchining manzili.

printf("%d", a);

a o‘zgaruvchisidagi butun sonni ekranga chiqaradi.

03 · C++ tilida

C++ da scanf() va printf()

C++ da ham scanf() va printf() dan foydalanish mumkin. Buning uchun odatda <cstdio> kutubxonasi ishlatiladi.

C++ kodi — C uslubidagi funksiyalar
#include <cstdio>

int main() {
    int a;
    std::printf("Son kiriting: ");
    std::scanf("%d", &a);
    std::printf("Natija: %d\\n", a);
    return 0;
}
Muhim: C++ — C tilining shunchaki boshqa nomi emas. C++ C dan rivojlangan alohida til, lekin unda C uslubidagi scanf() va printf() funksiyalaridan ham foydalanish mumkin.
04 · C++ ning odatiy usuli

C++ da cin va cout

C++ dasturlarida ma’lumot kiritish va chiqarish uchun ko‘pincha cin va cout ishlatiladi.

Kutubxona: <iostream>cin — kiritishcout — chiqarish
C++ kodi — cin/cout usuli
#include <iostream>
int main() {
    int a;
    std::cout << "Son kiriting: ";
    std::cin >> a;
    std::cout << "Natija: " << a << '\\n';
    return 0;
}

cin >> a;

Qiymatni kiritadi. >> operatoridan foydalanadi.

cout << a;

Qiymatni chiqaradi. << operatoridan foydalanadi.

06 · Format belgilar

%d, %f va & belgilarining vazifasi

%d

Butun son

int qiymatni o‘qish yoki chiqarish uchun.

scanf("%d", &a);
%f

Haqiqiy son

scanf() da float kiritish uchun, printf() da kasrli qiymatni chiqarish uchun.

scanf("%f", &x);
&a

Manzil

scanf() qiymatni qaysi o‘zgaruvchiga yozishini bilishi uchun manzil beriladi.

>> / <<

C++ operatorlari

cin >> a kiritadi; cout << a chiqaradi.

09 · Xulosa

Asosiy fikrlar

C tilida scanf() ma’lumotni kiritadi, printf() esa ekranga chiqaradi. Bu funksiyalar C++ da ham <cstdio> kutubxonasi orqali ishlatilishi mumkin. Biroq C++ da odatda cin kiritish va cout chiqarish uchun ishlatiladi; ular <iostream> kutubxonasiga tegishli. Demak, ikki tilda ham kiritish va chiqarish mumkin, lekin yozilish usuli va kutubxonalari farq qiladi.
