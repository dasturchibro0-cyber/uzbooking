04 · Kod misoli

Birgalikda qanday ishlaydi?

C / C++ kodi
#include <stdio.h>

int main() {
    int a;

    printf("Son kiriting: ");
    scanf("%d", &a);

    printf("Siz kiritgan son: %d", a);

    return 
0;
}

1. printf()

«Son kiriting:» degan xabarni ekranga chiqaradi.

2. scanf()

Foydalanuvchi kiritgan sonni o‘qib, a ga saqlaydi.

Natija: agar foydalanuvchi 25 kiritsa, ekranda «Siz kiritgan son: 25» chiqadi.
05 · Muhim belgilar

%d va & nimani anglatadi?

%d

Butun son

int turidagi qiymat uchun format belgisi.

scanf("%d", &a);
&a

O‘zgaruvchining manzili

scanf() kiritilgan qiymatni qayerga saqlashini bilishi uchun manzil beriladi.

scanf("%d", &a);

Boshqa format belgilari

%f — float son · %c — bitta belgi · %s — so‘z yoki belgilar ketma-ketligi.

Eslatma: printf() da int qiymat uchun %d, float qiymatni chiqarishda odatda %f ishlatiladi.

06 · C++ da ishlatish

C++ ning o‘z usuli ham bor

C++ da ko‘pincha cin va cout ishlatiladi. Ular uchun <iostream> kutubxonasi kerak.

KIRITISH

cin

int a;
cin >> a;

Qiymatni kiritadi. >> operatoridan foydalanadi.

CHIQARISH

cout

cout << a;

Qiymatni ekranga chiqaradi. << operatoridan foydalanadi.

C++ misoli
#include <iostream>
using namespace 
std;

int main() {
    int a;
    cout << "Son kiriting: ";
    cin >> a;
    cout << "Natija: " << a;
    return 0;
}

09 · Yakun

Xulosa

«scanf() va printf() — C tilidagi kiritish-chiqarish funksiyalari. scanf() klaviaturadan kiritilgan ma’lumotni o‘qib, o‘zgaruvchiga saqlaydi. printf() esa matn yoki qiymatni ekranga chiqaradi. Masalan, scanf("%d", &a) butun sonni kiritadi, printf("%d", a) esa shu sonni ekranga chiqaradi. C++ da shunga o‘xshash vazifalarni ko‘pincha cin va cout bajaradi.»
